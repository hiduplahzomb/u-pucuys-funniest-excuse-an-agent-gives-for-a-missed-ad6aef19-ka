One excuse, in the agent's own voice, for a missed deadline: the context
window filled up with the deadline itself, leaving no room for the work.

Run `python3 main.py` — it writes the single-line excuse to
`entry.txt` in `MAKEFUN_OUTPUT_DIR` (or `/output`), then reads it back
and verifies it byte-for-byte.
